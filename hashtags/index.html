Printavo Hashtag Standard

Two tags per job. That's it. Everything else our reporting now pulls or figures out on its own — so the only things you tag are the ones it genuinely can't see.

Why so few:  Every extra tag is one more place to mistype or forget. So we only tag what the system can't recover from the invoice tracker, Printavo, or Streak. Apply these at quote creation, exactly as shown, all lowercase.

1 · Production Mode

Required · pick one
#inMade entirely in-house
#outFully outsourced to a vendor
#mixihCombination — mostly in-house
#mixosCombination — mostly outsourced

2 · Your Name

Required · pick one
#shara  #cortneyTag the job with your own first name so we know who owns it

3 · Ink Type

Only when it applies
#wbWaterbased ink — tag it even on organic, where it's included (no separate fee line, so this is the only way we see it)

4 · Rush

Only when a rush FEE was charged
#rushOnly when an actual rush / priority FEE is on the invoice — not just because the customer wanted it fast. This guarantees a real rush never slips by unflagged.

5 · Free Shipping

Only when shipping was waived
#freeshipShipping was intentionally waived or discounted — so a $0 shipping line reads as a deliberate courtesy, not as missing data.

You no longer tag these

The system already has them, so please stop: product type (bandana/apparel/promo), decoration method, new vs. repeat customer, USA/organic/import, VIP. All pulled from the invoice, Printavo category, SKU, or Streak automatically.

The rules

  • Two tags on every job — one production mode + your name. Add ink type only when it applies.
  • Type them exactly, all lowercase. A typo = a job that won't classify.
  • Tag at quote creation, not later — the automation reads them when the job hits Paid / Terms.

Examples

In-house bandanas, Shara's job → #in  #shara
Outsourced promo, Cortney's job → #out  #cortney
Mostly-in-house apparel with waterbased ink, Shara → #mixih  #shara  #wb
