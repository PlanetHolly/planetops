The QC Gate — Checklist

The QC Gate is owned by the Operations Coordinator (Malia) and run by whoever covers it on her off-days. Every order passes through the gate before it goes to production — the gate-runner catches what doesn't add up, for the sales team and the production team, while there's still time to fix it.

This is the gate-runner's anchor (wherever it says "you," it means the person running the gate). You will not know every answer at first, and you're not supposed to. The gate is step by step, top to bottom. Start at the top of the order, work straight down, and you'll catch what matters.

When you run it

  • Run the gate on every order that lands in Paid → Blanks-to-Order status. That's the trigger — the moment an order becomes a real, push-to-production project (it's also what sends the alert email).
  • Open the order in Admin / edit view — not the public invoice. The public view is what the customer sees; you need the full deconstructed version to actually check it.
  • One order at a time. Top to bottom. Don't skip down — once it's out of sight, it's out of mind.
On your off-days This checklist is built so anyone can run it — it's not "only Malia." Mondays, or any day you're out, someone else opens the same list and runs the same steps.

The 12 steps

1Open it right

Order is in Paid → Blanks-to-Order. Open Admin / edit view. Start at the very top.

📷 Screenshot slot — capture & save as images/step-01-admin-view.png The order open in Admin / edit view, with "More options → Public invoice" visible — so the difference between admin view and what the customer sees is obvious.

2Top box — who & how

Note the owner (the rep — Shara on bandanas, Cortney on apparel) and the ship method. PO number and created date aren't your concern — skip them.

3The date triangle — spend time here

Line up three dates:

  • Production due date
  • Customer's in-hands / due date
  • Shipping transit time (how many days to get there)

Do they fit together? Cross-check the Production Availability tool for that day's capacity. Is the order even scheduled yet? If it's tight, that's a flag — bring it to Jean's attention (don't panic-flag; just make sure he's aware).

📷 Screenshot slot — capture & save as images/step-03-dates.png The invoice header showing production due date + customer due date side by side, and a capture of the Production Availability tool for the relevant day.

4Production notes

Read them. Hard deadline? Anything unusual? Is there a press-check note where it should be?

5Shipping notes

Special labels, box markings, convention-center markings, overnight shipping — anything the floor needs to know to ship it right.

6Blanks & inventory

Check live inventory against the quantity needed. Is there enough? If it's low, flag it. (Bandana ordering math — the 50-dozen logic, pick-and-pull — stays with Jean for now; he fills in the blanks notes.)

📷 Screenshot slot — capture & save as images/step-06-inventory.png The live inventory readout on a line item — quantity needed vs. quantity on hand (a low-stock example is ideal so the flag is clear).

7Art vs. separation file — the big one

Does the attached separation file match the mockup? Size, dimensions, content. If it's a reprint, go investigate the previous order's folder as a fact-check (not to rely on — to verify).

The Peekskill rule On the Peekskill hoodie, the mockup said 12″ but the attached separation file was 10″ — caught on press, against the deadline. The attached file not matching the mockup is your first flag, every time. That's the whole reason this gate exists.
📷 Screenshot slot — capture & save as images/step-07-art-vs-sep.png The mockup and the attached separation file shown together, with the imprint dimensions visible on each — so the match (or mismatch) is the thing you see.

8Color

Verify the PMS / Pantone color was chosen from the physical Pantone book, not just off the screen. Cross-check the number. The press mixes ink from that number — it has to be right.

9Tags / hashtags

Confirm the tags: in-house vs. outsourced, client type, rep. These are how we filter and report — even when it's outsourced and comes back to us, it's still tagged outsourced.

10Hand-select the production file

Attach the exact production file the floor should print from — so no one digs through the folder and grabs the wrong version. This is the safety net.

11Final glance

Get out of edit mode. Go back to the overview and sweep top to bottom one more time. You'll catch the thing you meant to come back to.

12Sign off

Set the status to QC Complete and drop the /QC snippet ("QC'd by Malia"). Done.

📷 Screenshot slot — capture & save as images/step-12-signoff.png The order set to QC Complete status, plus the /QC text-blaze snippet expanded in the notes ("QC'd by Malia").

If something's off

You don't fix it yourself — you flag it to the right person while there's still time:

  • Timing / scheduling → Jean
  • Apparel art or customer questions → Cortney
  • Bandana art or customer questions → Shara

The goal is simple: nothing reaches production that doesn't add up. When you're not sure whether something's a real problem, ask — that's the job working, not the job failing.
