THE THREE RULES
  1. Bandana products are $0 on purpose. The matrix column is the ENTIRE per-piece price (blank + print together). Nothing gets added on top except shipping and card processing.
  2. Use only matrices that start with "Bandana". Any other bandana matrix name is retired — it now prices LOW because the product no longer adds its cost.
  3. Never hit "Refresh Pricing" on a bandana quote made before 2026-07-10. It will re-price low. If you must reprice an old quote: switch its imprint to the matching current "Bandana …" matrix first, then refresh.
