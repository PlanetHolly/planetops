File Naming & Folder Guide

How we name every folder, design, and file at Planet Apparel — so anyone on the team can find a project, pull a reorder, and send it to production without guessing. Learn this once and you will never lose a file again.

The one rule behind all of it A name is only useful if the most important word comes first and it reads the same way everywhere — Dropbox, the mockup, the invoice, the PO. Consistent names are how the whole shop stays in sync. Inconsistent names are how things get printed wrong.

Example client used throughout: The Crack Shack  ·  nickname: Egg Icon

1 · Folders

Setting up a customer folder

  1. Open Dropbox → ART. Search to confirm the client doesn't already have a folder.
  2. If new, make a Company Folder named after the company (or First + Last name if there's no company).
    The Crack Shack
  3. Inside it, make one Project Folder per project.

Project folder name

Garment_Project Name_Month Year

T-Shirt_Egg Icon Ladies Tank Top Print_Aug 2026
  • Garment is specific — T-Shirt, Bandana, Hoodie.
  • If one design runs across multiple apparel types (hoodie + tee + tank), set the garment to Apparel.
  • Dropped: the old _Item code at the end (e.g. _DM414). We no longer use it.

Inside the project folder

  • No type-based subfolders. The old Inner DST, Inner Art, Vendor Zip, and POs folders are gone — those are just files saved directly in the project folder.
  • Collection folders are allowed. You may group a client's projects under one inner folder when it helps you navigate (e.g. all of Iron & Velvet's projects together). Just keep naming each file properly so a single reorder is still findable.

Call out the logo name (front/back can be separate DSTs). Curved = hats; flat = everything else.
"High-Res" vs "Provided Art" — don't mix them up High-Res and Vector mean a file going OUT to a vendor (the DTF transfer you prepped). Anything the customer gave us stays Provided Art_… — even when it's a high-resolution file.
